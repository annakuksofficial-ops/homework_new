# Обработчик банковских операций

Python-модуль для фильтрации и сортировки банковских операций, маскировки карт и счетов и генерации данных.

## Описание

Модуль предоставляет функции для работы со списками банковских операций:

1. Фильтрация по статусу
2. Сортировка по дате
3. Маскировка номеров карт и счетов
4. Генераторы для обработки транзакций

## Фильтрация по статусу

```
from src.processing import filter_by_state

operations = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]

# Фильтрация по умолчанию (статус 'EXECUTED'):
result = filter_by_state(operations, 'EXECUTED')
# Результат:
# [
#     {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
#     {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
# ]

# Фильтрация по статусу 'CANCELED':
result = filter_by_state(operations, 'CANCELED')
# Результат:
# [
#     {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#     {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
# ]
```

## Маскировка карт и счетов
```
from src.masks import get_mask_card_number, get_mask_account
from src.widget import mask_account_card, get_date

# Маскировка номера карты
get_mask_card_number(7000792289606361)  # "7000 79** **** 6361"

# Маскировка номера счета
get_mask_account(73654108430135874305)  # "** 4305"

# Маскировка карты или счета с определением типа
mask_account_card("Visa Platinum 7000792289606361")  # "Visa Platinum 7000 79** **** 6361"
mask_account_card("Счет 73654108430135874305")       # "Счет **4305"

# Форматирование даты
get_date("2024-03-11T02:26:18.671407")  # "11.03.2024"
```
## Генераторы для обработки транзакций

```
filter_by_currency - фильтрует транзакции по валюте
transaction_descriptions - возвращает описания каждой транзакции по очереди
card_number_generator - генератор номеров банковских карт
```
## Декоратор логирования

В проект добавлен декоратор `log` из модуля `decorators.py`, 
который автоматически логирует выполнение функций. 

### Возможности декоратора:

Декоратор принимает необязательный аргумент 
filename, который определяет, куда будут записываться логи (в файл или в консоль):

Если filename задан, логи записываются в указанный файл.
Если filename не задан, логи выводятся в консоль.

## Обработка JSON-файла с транзакциями

Модуль `utils.py` для работы с JSON-файлами.

### Функция `load_transactions(file_path)`
- Принимает путь к JSON-файлу
- Возвращает список словарей с транзакциями
- Если файл не найден, пустой или содержит не список - возвращает пустой список
